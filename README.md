### Building

**SHOPLIFT** · `private` — store extraction & relocation suite. Config-driven WordPress → Shopify migration pipeline: resumable, idempotent, auditable. Zero runtime dependencies, 100% GraphQL Admin API, per-client workspaces and ledgers so a re-run never duplicates an order.

**[prompt-cortex](https://github.com/dnh33/prompt-cortex)** — invisible prompt intelligence for Claude Code. 350 expert prompts that inject themselves into your workflow.

**[frontend-aesthetics](https://github.com/dnh33/frontend-aesthetics)** — anti-AI-slop frontend skill for webshop development. Distinctive typography, purposeful motion, 2026 conversion data.

**[tasteful-llm](https://github.com/dnh33/tasteful-llm)** — eliminates AI slop from creative output. 39 anti-patterns, 5 mechanical checks, recursive router architecture.

**[markdown-fetch](https://github.com/dnh33/markdown-fetch)** — fetch web pages as clean markdown, with prompt-injection protection. 82–94% token savings.

**[ralph](https://github.com/dnh33/ralph)** — self-referential development loop and a brutally honest code roaster.

**[matrix-statusline](https://github.com/dnh33/matrix-statusline)** — animated katakana rain for your Claude Code status line, because terminals should have a pulse.
